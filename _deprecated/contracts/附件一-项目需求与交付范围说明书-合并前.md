### 2. 基于云器 CLI 的 MCP 开发

乙方基于云器 CLI 封装 MCP 工具，供数据开发 Agent 调用，使其能够读取生产数据，并在测试数据库中执行数据处理工作。

MCP 的操作范围为：

- **生产数据库：只读。** 允许读取授权范围内的数据，不允许写入、修改或删除生产数据，也不允许修改生产库结构。
- **测试数据库：读写。** 允许在授权范围内读取和写入数据，用于数据开发、数据清洗及数据治理。

Agent 通过 MCP 调用封装后的云器 CLI 能力执行数据库操作，生产库写入能力不向 Agent 开放。

### 3. 安全与审计

1. **操作审计。** Agent通过MCP发起的全部数据库读写操作均记录审计日志，包括发起人、运行时、操作时间、目标库表、操作内容及执行结果，被拒绝的操作和人工审批过程也应留痕。日志可查询、追溯，不明文记录密码、访问凭据或不必要的业务数据。

2. **运行时独立权限。** 每个Agent运行时单独配置数据源、库表及操作权限，通过独立身份访问MCP，由服务端校验权限。生产库使用只读账号，测试库使用限定范围的读写账号，不仅依赖模型提示词限制操作。

3. **高危操作拦截与审批。** 生产库写入、越权访问及权限修改等操作在MCP层直接拒绝，不因人工审批而放开。测试库清空、删表、大批量覆盖等高危操作，按双方确认的规则直接禁止或经人工审批后执行。封装云器CLI时仅开放必要命令，不向Agent提供任意Shell命令执行入口。

4. **内网隔离与加密访问。** 非公开数据处理所用的Agent执行服务、MCP服务及本地模型服务原则上部署在甲方内网，服务调用采用身份鉴权及TLS加密；外部人员通过VPN等受控入口访问，不直接向公网开放MCP及模型服务。云器支持私网接入时使用私网连接，仅支持公网接口时采用HTTPS及可用的访问白名单、受控出口措施。非公开数据不得发送至外部模型，本地模型不可用时不得自动切换至云端模型；日志上报、遥测及第三方工具也应遵守同样的数据边界。具体网络接入方式由双方根据甲方环境及云器支持能力确认。

## 第二部分：OA业务协同平台

系统按销售、产品、研发、管理员四类角色提供不同的工作视图，根据登录人员的角色及授权，展示对应的菜单、数据和操作入口。销售侧重客户及需求管理，产品侧重方案、承接安排和验收，研发侧重任务执行与交付，管理员负责需求承接审批、权限及系统管理。

各模块的开放角色如下；模块可见不代表具有全部操作权限，人员仅能在授权数据范围内执行对应操作。客户档案管理向销售和管理员开放，客户沟通及录音总结功能仅向销售开放。

### 1. 核心业务流转

**开放角色：** 销售、产品、研发及管理员按各自职责参与。

**销售创建需求 → 指定审批人审批 → 产品接收并安排承接 → 产品或研发执行 → 提交交付 → 产品验收。**

1. **销售创建需求。** 销售选择关联客户，填写需求说明、交付要求及附件，保存后提交承接审批。
2. **管理员审批。** 提交后由后台指定的管理员判断是否承接。通过后流转至产品处理；不通过则记录审批意见并通知销售，项目不进入后续实施环节。
3. **产品处理需求。** 产品查看需求、补充方案信息，并决定由谁承接执行。产品可以自己承接，也可以直接指派一位或多位研发人员。
4. **灵活承接与转交。** 产品自己承接后，可以继续完成交付，也可以将任务转交给研发。转交时保留已有说明、附件及处理记录，并可填写交接说明。流程中保留“产品承接”记录，追加“研发承接”记录，不覆盖之前的承接过程。
5. **执行与提交交付。** 当前承接人处理任务，填写交付说明、上传相关附件，并在交付信息中提交成果。研发提交后，系统通知产品进行验收，提交交付不直接等同于验收完成。
6. **产品验收。** 产品核对交付结果，选择通过或退回修改；退回时填写意见，由承接人继续处理后重新提交。通过后记录验收人、时间及结果，并通知销售和相关参与人员。产品自行承接时的成果确认人员及规则，待双方确认。

需求审批、任务指派、转交、提交交付及验收均由人员在系统中操作，Agent仅作为辅助工具，不自动决定是否承接或推进业务状态。

### 2. 各角色功能

- **销售：** 管理客户及沟通记录，提交需求，跟进项目与交付进度。
- **产品：** 编写方案，自行承接或指派、转交研发，验收研发交付成果。
- **研发：** 处理分配的任务，提交交付成果，并按验收意见修改。
- **管理员：** 处理承接审批及Skill上架审核，管理客户、全部项目、人员与Agent权限及运行时授权，查询审计日志，详见第8项“管理员页面”。

### 3. 客户管理与沟通记录

**开放角色：** 销售、管理员。其中客户沟通及录音总结功能仅向销售开放。

- **客户档案：** 维护客户基本信息、联系人及跟进情况，查看关联需求和项目。
- **客户沟通：** 按“销售拜访”“客户会议”区分记录，展示沟通时间、组织人及参与人员。
- **录音及总结：** 提供新建录音入口，支持保存沟通录音、查看文字转写及AI总结，并将相关内容关联到对应的客户沟通记录。

### 4. 项目信息与交付管理

**开放角色：** 销售、产品、研发、管理员。销售查看和维护其负责的需求，产品处理其负责的方案、承接安排和验收，研发处理分配给自己的任务与交付；管理员按授权查看及管理项目。

- **项目列表：** 根据人员角色和权限查看需求、本人参与项目或全部项目，支持按状态筛选。
- **项目详情：** 展示项目名称、参与人员、当前研发承接人、流程进度及交付安排；已完成、进行中及待开始的节点使用对应文案。
- **信息维护：** 设置“需求信息、方案信息、交付信息、流转记录”四个标签页，前三项以可编辑文本和附件为主，按职责及授权维护。
- **交付安排：** 支持一次性交付和分批交付；一次性交付记录交付日期，分批交付记录并更新下次交付日期。交付安排由销售或管理员维护，其他人员查看。
- **记录保留：** 保存审批、承接、转交、提交交付、验收及退回记录，显示操作人、时间和处理意见。

### 5. 系统通知

**开放角色：** 销售、产品、研发、管理员。

每个人均有系统通知入口，接收与自己相关的项目状态变化及待处理事项，支持未读标识和跳转对应项目。

### 6. Agent对话与运行时管理

**开放角色：** 销售、产品、研发、管理员均可使用Agent对话及查看本人获准使用的运行时；云端运行时管理操作仅向具备相应管理权限的人员开放。

**数据开发Agent接入：** 第一部分开发的数据开发Agent将作为云端运行时接入本平台，纳入Agent管理。获授权人员可在Agent对话中选择该运行时，通过自然语言开展数据开发、清洗及治理工作。该运行时遵循第一部分约定的数据分类、模型调用、数据库权限及安全审计规则。

- **Agent对话：** 支持新建会话、查看历史会话、会话置顶及归档；不同岗位可围绕各自工作使用Agent。
- **Agent管理：** 展示云端及本地运行时、支持的Agent及可用状态，区分“全部”和“我的本地”。本地运行时提供新建入口，具体接入和部署方式待双方确认。
- **使用授权：** 管理员可为每个人指定允许使用的云端运行时，人员只能在授权范围内选择。OA中的运行时使用权限与第一部分的数据库操作权限分别控制。

### 7. Skill广场

**开放角色：** 销售、产品、研发、管理员。

提供公司内部Skill广场，支持查看、创建、编辑及提交发布Skill。提交发布后进入待审核状态，经管理员审核通过后方可上架，供人员安装到本人有权使用且允许安装的指定运行时；审核不通过的，提交人可根据审核意见修改后重新提交。未通过审核的Skill不在广场上架，也不提供安装使用入口。

**服务范围：** 乙方仅提供上述平台功能，具体Skill由甲方自行开发和维护；本合同不包含乙方为甲方开发或协助开发具体Skill的服务。

### 8. 管理员页面

**开放角色：** 管理员。

1. **需求承接审批：** 查看销售提交的需求，区分待审批和已审批；查看需求详情、提交人及交付要求，选择“审批通过，决定承接”或“拒绝承接”，保留审批记录并通知相关人员。支持配置需求承接审批人。
2. **全部项目管理：** 查看全部项目，按状态筛选，查看需求、方案、交付信息、附件、参与人员及流转记录；维护项目基本信息和交付日期。
3. **客户管理：** 查看全部客户，维护客户基本信息、联系人及跟进情况，查看关联需求和项目。
4. **人员权限管理：** 查看人员及角色，分别配置销售和管理员的客户管理只读或编辑权限、人员的项目基本信息只读或编辑权限，以及项目指派、审批处理和云端运行时管理权限。项目指派仅向产品开放，审批处理仅向指定管理员开放。
5. **云端运行时授权：** 为每个人选择可使用的云端运行时，支持多选；未授权的运行时不向该人员提供使用入口，包括第一部分接入的数据开发Agent运行时。
6. **Agent权限管理：** 与人员权限分开管理，按Agent运行时配置生产库读取及测试库读写权限。生产库仅可配置禁止访问或只读，不开放写入权限；权限控制遵循第一部分的安全规则。
7. **审计日志：** 查看人员操作、Agent操作、权限变更及被拦截的操作记录，展示时间、操作者、操作内容、目标资源和结果；支持分类筛选、关键词搜索及日志导出。
8. **Skill上架审核：** 查看待审核及已审核的Skill，查看提交内容，作出通过或不通过的决定并记录审核意见；通过后上架，不通过则退回提交人修改。保留审核人、时间及结果，并向提交人发送系统通知。

管理员同时可使用前述系统通知、Agent对话、Agent管理及Skill广场功能。

### 9. 安全与审计

1. **私有化部署：** OA平台服务、业务数据库及附件存储部署在甲方提供并控制的服务器环境中，可使用甲方自行采购的本地服务器。客户资料、项目文档、沟通录音及会话记录存储在该环境内；涉及AI处理时，遵循第一部分的数据分类规则，非公开数据使用本地模型，不发送至外部模型服务。
