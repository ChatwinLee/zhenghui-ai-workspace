# 合同文档排版规范

确认日期：2026年9月28日。

## 当前工作方式

先编辑和确认《软件项目委托开发合同-草稿.md》，包括合同正文及需求范围附件。Markdown 为当前内容主稿，暂不继续生成 Word。待内容确认或用户要求转换时，再按以下规范排版。

## 已确认的 Word 格式

| 项目 | 采用格式 |
| --- | --- |
| 纸张 | A4，纵向 |
| 主标题 | 二号黑体，22 磅，居中 |
| 条款标题 | 四号黑体，14 磅 |
| 正文 | 四号宋体，14 磅，两端对齐 |
| 页边距 | 上下 2.54 厘米，左右 3.175 厘米 |
| 正文行距 | 固定值 22 磅；这是本稿已确认的排版选择 |
| 签署部分 | 单独成页，保留签字、盖章空间 |

## 后续转换注意事项

- 保留正文及两份附件的层级：附件一为项目需求与交付范围说明书（包含分阶段交付计划），附件二为需求变更确认单；付款节点列在正文第三条。
- 不以字体替代、自动缩小字号等方式改变已确认格式；如环境缺少黑体或宋体，先解决字体问题。
- 检查中文字体显示、分页、标题与正文衔接，以及签署页空间。
- 不添加标题下的装饰横线。
- 内容尚在讨论中的金额、日期、期限、责任及功能范围继续保留待确认标记，不自行补定。
